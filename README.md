# Python Simple Programs

Beginner-level Python programs ka collection. Har program ek file mein hai aur seedha run ho jata hai.

## Folders

| Folder | Topic | Programs |
|---|---|---|
| `01_basics` | Basics | Hello World, Add Numbers, Calculator, Swap, Circle Area, Temperature Converter |
| `02_conditions` | if / else | Even-Odd, Largest of Three, Leap Year, Grade Calculator, Positive-Negative |
| `03_loops` | Loops | Table, Factorial, Fibonacci, Prime, Sum of Digits, Reverse Number, Armstrong, Star Patterns |
| `04_strings` | Strings | Palindrome, Vowels Count, Reverse String, Word Counter, Anagram, Caesar Cipher |
| `05_lists_and_data` | Lists / Dict | List Operations, Remove Duplicates, Bubble Sort, Binary Search, Dictionary, Matrix Addition |
| `06_functions` | Functions | Functions Demo, Recursion, GCD and LCM |
| `07_oop` | OOP | Class and Object, Inheritance, Bank Account |
| `08_files_and_misc` | Files / Games | File Handling, Guessing Game, Rock Paper Scissors, To-Do List, Exception Handling |

## Kaise run karein

```bash
python 01_basics/hello_world.py
```

Python 3.8 ya us se naya version chahiye.
